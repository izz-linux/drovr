# Insights (spend log, chart colors, overview) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Record what every run costs, and show it in an Insights view, in every theme.

**Architecture:** A `spend` table gets a row per run and model when a run ends. `Engine::insights` adds it up for the view, which draws it with plain markup and theme colors. Older runs come from the ticket ledgers, once.

**Tech Stack:** Rust (`drovr-core`, Tauri `drovr-app`), Svelte 5, pnpm. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-24-insights-design.md`. This covers its build order 1 to 3; per-PR numbers and topics come with 4 and 6.

## Global Constraints

- Spend is recorded with `workflow.enabled` off. Never prompts, messages or task text.
- A cost the CLI didn't report is NULL, never 0.
- Model names go through `models::canonical`; the name as started is kept.
- Every color is a theme variable. README and USAGE change with the code. Coverage stays above 80%.
- Each task is its own PR, one-line Conventional Commit message, no trailers.

## Review Focus

- A failed write to `spend` must not stop a run from finishing.
- An agent removed and made again under the same name must not overwrite its earlier runs.
- One run on two tickets must be imported once, and split between them.
- Two processes importing at once must import once.
- A week with no runs shows as a gap of zero, and an empty database as an empty state.
